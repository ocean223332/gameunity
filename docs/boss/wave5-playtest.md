# Wave 5 commander playtest

Open Builds/Windows/TienTuyen.exe (ship the entire Windows folder, not the EXE alone).

- F9: start wave 5 immediately, even from the menu; run is marked TEST.
- F6: toggle invulnerability.
- F10: add 1,000 supply.
- Hold Space for 0.6 seconds: skip the boss intro/retreat scene.
- Esc: pause/resume; mouse remains available to use the pause menu during a cutscene.
- F7: skips regular waves, does not bypass a living commander.

Boss has 1,000 HP. A red circle warns the locked impact position 1.8 seconds before launch; leave it or use solid cover. Crouching does not avoid the blast. The boss repositions during the cooldown.

After defeat and the retreat scene, the run receives an RPG-18, +20 bonus supply and one free launcher-upgrade selection. Regular survival rewards are separate. If all four gun slots were occupied, the launcher replaces the held gun; otherwise it is added. The reward cannot be claimed twice.

Choose a launcher upgrade, finish any queued upgrades, leave the shop and use scroll/Q/number keys to select the RPG. It has one round and automatically reloads. Specific upgrades increase damage or blast radius, or shorten reload, to a maximum of three levels per branch.

English voice is currently a local synthetic placeholder, with Vietnamese subtitles. This release implements the wave-5 milestone in the existing six-wave run. The ten-wave/M113/airstrike campaign is not part of this build.
